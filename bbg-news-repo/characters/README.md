# BBG News character souls

BBG News makes short, unofficial fan films starring the eleven classes of SkyVu's *Battle Bears Gold* (BBG). This folder holds one "soul" per character, plus [STYLE.md](STYLE.md), the house style every short is drawn in.

## What a soul is

A soul is the working bible for one character. Writers, animators, voice casting and prompt tools all work from it, so the same bear acts, sounds and looks the same in every short. Every soul has the same sections in the same order:

**Canon anchor** (official quotes) · **Soul** (wants, fears, the contradiction that makes them funny, values, comedy engine) · **Voice** · **Relationships** · **Look (for animation)**, including **Weapons** · **Movement & acting** · **Story engine** · **Prompt pack** · **Canon vs invention ledger** · **Open questions**

Every claim carries a label, so you can always tell what SkyVu said from what fans or BBG News added.

## Labeling legend

| Label | What it means | How to use it |
|---|---|---|
| `[Canon]` | An official SkyVu source: battlebears.com, store pages, patch notes, credits, trailers | State as fact |
| `[Canon card]` | A SkyVu character description card (the image is hosted on the fan wiki) | State as fact |
| `[Canon, channel unconfirmed]` / `[Canon, unviewed]` | Looks official, but the YouTube channel isn't confirmed as SkyVu's, or nobody has watched it yet | Attribute it; don't lean on it |
| `[Game text via wiki]` | In-game item, skin or class text as the fan wiki quotes it, not checked against the game files | Say "the in-game text, as the wiki quotes it" |
| `[Press]` | Contemporary press coverage (e.g. TouchArcade, 2010) | Attribute it |
| `[Observed]` | What a researcher saw in official art or screenshots; a reading, not an official spec | Use for design |
| `[Inference]` | A researcher's reasoning from the sources, including hex colours sampled from official art | Not fact |
| `[Fan-wiki]` | The Battle Bears fandom wiki: barks, taunts, skins, kits, plot details | Fan material |
| `[Fan-wiki, Unverified]` | A wiki claim whose underlying source nobody has seen (e.g. the Oliver–Astoria crush) | Fan material; never imply it's canon |
| `[BBG News invention]` | Made up for BBG News: dynamics, new lines, gags, loglines, heights, placeholder hexes | Fan material |
| `[Open]` | Unresolved; see the file's Open questions | Don't decide it on screen |

A qualifier after a comma (a year, "BBH-era site", "archived 2024") narrows a label without changing it.

## House style for BBG News shorts

- **Rendering.** Every short, model sheet and prompt uses the feature-film 3D house style Bryce chose on 2026-10-17, which replaces the earlier low-poly mobile-game style. [STYLE.md](STYLE.md) has the full rules: the look, the habits that keep it from looking generic, and the prompt wording. Every prompt pack uses that wording:
  - Model sheets: "Fan-art character model sheet (front, side, back and three-quarter views) of *Name*, *description*; polished stylized feature-film 3D animation character, soft rounded shapes, expressive face, soft plush fur, clean painted metal robot parts, bold readable silhouette. Neutral grey background, even studio lighting, no text."
  - Video starters end with the video suffix: "Polished feature-film 3D animation, soft rounded shapes, expressive faces, soft plush fur, soft global illumination, cinematic lighting, snappy cartoon timing with strong poses and holds."
  - Every soul's model sheet and video starter end with this wording word for word, B-1000's and Astoria's included. A soul changes a shared phrase only where it would work against that character; the change is listed in STYLE.md, and the soul's Prompt pack says why. The only such change is Saberi's negative list, which says "extra paws, extra legs, a second mechanical arm" in place of "extra limbs", so it doesn't fight her third arm. Astoria and B-1000 handle the mismatch in their own description and negatives instead: Astoria's description adds "clean painted metal buckles, clips and scope fittings", because she has no robot parts; B-1000's description keeps him all painted metal, and his solo-shot negative adds "fur, plush texture" (a no-fur variant of the strings would first have to be added to STYLE.md).
- **Era.** Default to each character's BBG 2013 default skin, the in-game 3D model. Pick one era per short and say which. SkyVu's Steam trailer and screenshots are most likely re-edited 2013 launch footage [Inference, strong], so caption anything taken from them "classic 2013 look", never "2026 gameplay".
- **Exceptions** are explained in each file: Saberi (she debuted in late 2013, so she is dressed from her 2014 official art) and Riggs (his 2013 outfit carries the 2026-banner Beebeegun model, a labelled BBG News pick). Wil and Graham are no longer exceptions, because their in-game defaults are now documented. Wil no longer needs the c. 2012 card and 2012 frame as stand-ins. Graham now wears his in-game 3D default, which every in-game weapon shot needs, and the 2013 trailer card that made his default uncertain turned out to be the Instagraham skin; his card look is kept for card-era shorts, posters and flashbacks. Other eras (BB-1 or BB Zombies 2D, 2024 BB Heroes portraits) are only for clearly marked flashbacks or skin gags.
- **Team colour:** red team by default. BBG 3D gear is team-coloured, so on the blue team the same skin's team-coloured parts turn blue [Fan-wiki; Observed].
- **Scale chart** (head height, Oliver = 1.0×) [BBG News invention]: B-1000 ~1.5×, the biggest · Riggs ~1.2×, the broadest bear · Oliver, Astoria (slimmer), Graham (stooped, reads shorter), Saberi (third arm reaches ~1.4×), Sanchez (lean; right arm ~1.5× the left) and Botch (hovering, slighter body) 1.0× · Wil ~0.9×, pear-shaped · Tillman ~0.9×, as wide as Riggs · Huggable ~0.65×, the shortest, a head below Wil.
- **Pronouns:** B-1000 is "he", the Huggable is "it", ABBi is "she".
- **Tone:** slapstick and deadpan. Make 15–45 second single-gag shorts that end on a hard cut, like the BB-1 cutscenes' "Hugged to DEATH!" endings. Arena matches and training bouts contradict nothing official. The joke is the character's contradiction, never an accent or a real-world group.
- **Teen rating (13+):** cartoon violence only. No blood, gore or organs. A KO is a floppy, intact pratfall or a pop into a few clean toy pieces [Observed]. Bears throw sparks and robots shed bolts and plates [BBG News invention; B-1000 really breaks into head, plates, claws and gun, Observed]. Melee contact pops a cluster of yellow five-point cartoon stars [Observed: 2013 and 2021 footage, and SkyVu's 2013 launch-trailer footage re-used on Steam in 2026]. The Sci-Fi rifles glow and hit in magenta [Observed]. Huggables break into plush pieces with gold sparkles [Observed] or show white stuffing and a vertical rainbow column, as on SkyVu's merch art [Canon, merch art]. Rainbow confetti is [BBG News invention], so never present it as the in-game look. Swearing is bleeped, cut off or swapped for a minced oath, after SkyVu's "WARNING! FCC Censorship!" gag. No slurs, sexual content or innuendo, crude taunts (Tea-Bagging is out), tobacco, alcohol or drugs.
- **Voices:** cast original performers only. Never clone or imitate a real person's voice; credited actors are history, not targets. Fan audio rips are for checking wording only.
- **Shared negative prompt:** add this to every file's own list: photorealistic fur, realistic anatomy, blood, gore, sexual content, real-person likeness, official logos, text, watermarks, morphing, extra limbs, low-poly, flat 2D.
- **End card,** on every short, word for word:

  > Unofficial fan film, not affiliated with SkyVu; characters © SkyVu.

## Weapons

Each soul's **Weapons** section, under Look, summarises the verified weapons research for that class: the default loadout and how it is carried, the kit, and each weapon's look, firing and impact, with notes on showing it in shorts and what is still unknown. The full dossiers, with every source, frame and sampled hex, live in `research_notes/BBG weapons (verified)/` in the Thallo site repo; start with `00_OVERVIEW.md`. That folder is not part of this repo. Labels are carried over from the dossiers and never upgraded. The dossiers also use `[Unverified]`, which the legend lacks; some souls write it as `[Open]` and some keep it. Either way it means nobody has confirmed the point, so treat it as `[Open]`. Several dossiers also tag hex values sampled from BBG game images `[Observed, sampled]`, while the legend above files sampled hexes under `[Inference]` and 00_OVERVIEW §3.2 calls them estimates `[Inference]`. Some souls keep the dossier tag with a label note and some write `[Inference]`. Within one file a sampled value keeps one tag, and either way it is an estimate, never an official code.

## Rule: fan material stays fan material

Anything labeled `[Fan-wiki]`, `[Fan-wiki, Unverified]`, `[Inference]` or `[BBG News invention]` is fan material. In shorts, captions, descriptions and posts, present it as fan material and never as SkyVu canon: no "officially", no "in the lore", nothing that implies SkyVu confirmed it. When a short is built on it (Oliver's one-sided crush on Astoria, Sanchez's unfinished rescue, a "what if" where Saberi upgrades Sanchez's arm), its description says it is a fan take. Quote `[Game text via wiki]` as "the in-game text, as the wiki quotes it".

Continuity: a dynamic between two characters appears in both files with the same wording and label, so change both or neither. Standing decisions: the Oliver–Astoria romance is not canon; no one is named as Sanchez's rebuilder; Riggs is not assumed to be the "Captain" Tillman begs to charge.
