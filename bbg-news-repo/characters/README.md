# BBG News character souls

BBG News makes short, unofficial fan films starring the eleven classes of SkyVu's *Battle Bears Gold* (BBG). This folder holds one "soul" per character, plus [STYLE.md](STYLE.md), the house style every short is drawn in.

## What a soul is

A soul is the working bible for one character. Writers, animators, voice casting and prompt tools all work from it, so the same bear acts, sounds and looks the same in every short. Every soul has the same sections in the same order:

**Canon anchor** (SkyVu's own words, each with its label) · **Soul** (wants, fears, the contradiction that makes them funny, values, comedy engine) · **Voice** · **Relationships** · **Look (for animation)**, including **Weapons** · **Movement & acting** · **Story engine** · **Prompt pack** · **Canon vs invention ledger** · **Open questions**

Every claim carries a label, so you can always tell what SkyVu said from what fans or BBG News added.

Two terms every Prompt pack uses (STYLE.md, Prompt wording):
- **Element:** the saved character reference in the generator, built from the soul's approved model sheet and named with the soul's "Short name for tools" (for example `riggs-heavy`). Its hands must match the shot: use the soul's empty-handed sheet or the sheet made for that loadout, as the soul's Prompt pack says [BBG News invention].
- **Paste-ready text:** in every Prompt pack, the paste-ready text is everything inside the quotation marks, and nothing else. Labels in square brackets and every line marked "not for pasting" (or "do not paste", as oliver.md and sanchez.md write it) are for the editor and never go into a tool [BBG News invention].

## Labeling legend

| Label | What it means | How to use it |
|---|---|---|
| `[Canon]` | An official SkyVu source: battlebears.com and the 2011–2014 SkyVu blog, store pages, patch notes, credits, trailers, and official video titles and descriptions | State as fact |
| `[Canon card]` | A SkyVu character description card (the image is hosted on the fan wiki) | State as fact |
| `[Canon, comic page via wiki]` | Text from Chapter 1 of SkyVu's comic, which carries SkyVu's story credits but survives only as page scans on the fan wiki | State as fact; say it is from SkyVu's comic |
| `[Canon, channel unconfirmed]` / `[Canon, unviewed]` | Looks official, but the YouTube channel isn't confirmed as SkyVu's, or nobody has watched it yet | Attribute it; don't lean on it |
| `[Game text via wiki]` | In-game item, skin or class text as the fan wiki quotes it, not checked against the game files | Say "the in-game text, as the wiki quotes it" |
| `[Press]` | Contemporary press coverage (e.g. TouchArcade, 2010) | Attribute it |
| `[Observed]` | What a researcher saw in an image or frame they actually opened: official art, SkyVu video, wiki-hosted images, or fan footage and thumbnails, with a qualifier or the sentence naming any fan source (e.g. `[Observed, fan video]`); a reading, not an official spec | Use for design |
| `[Inference]` | A researcher's reasoning from the sources, including hex colours sampled from game images, frames and thumbnails (estimates, not official codes) | Not fact |
| `[Fan-wiki]` | The Battle Bears fandom wiki: barks, taunts, skins, kits, plot details | Fan material |
| `[Fan-wiki, Unverified]` | A wiki claim whose underlying source nobody has seen (e.g. the Oliver–Astoria crush) | Fan material; never imply it's canon |
| `[BBG News invention]` | Made up for BBG News: dynamics, new lines, gags, loglines, heights, placeholder hexes | Fan material |
| `[Unverified]` (also the fan-only tags `[Fan video titles]` and `[fan claim, InstableGR]`) | A research label: nobody has confirmed it, or it rests only on fan uploads | Treat exactly as `[Open]` |
| `[Open]` | Unresolved; see the file's Open questions | Never present it as settled or build a plot on it. Where a model sheet must still show something (a side, a colour, a size), the soul makes one labelled `[BBG News invention]` pick and keeps it in every shot; the point itself stays `[Open]` |

A qualifier after a comma or colon (a year, a source such as "fan video", "BBH-era site", "archived 2024", "strong") narrows a label without changing it. ", Unverified", ", channel unconfirmed" and ", unviewed" are not qualifiers but part of the label: never drop them, in files, scripts, captions or posts. A label may be carried over or weakened, never upgraded.

## House style for BBG News shorts

- **Rendering.** Every short, model sheet and prompt uses the feature-film 3D house style Bryce chose on 2026-10-17, which replaces the earlier low-poly mobile-game style. [STYLE.md](STYLE.md) has the full rules: the look, sets and light, the habits that keep it from looking generic, the prompt wording and sound. Every prompt pack uses that wording:
  - Model sheets: "Fan-art character model sheet (front, side, back and three-quarter views) of *Name*, *description*; polished stylized feature-film 3D animation character, soft rounded shapes, expressive face, soft plush fur, clean painted metal robot parts, bold readable silhouette. Neutral grey background, even studio lighting, no text."
  - Video starters end with the framing line "Vertical 9:16 framing." and then the video suffix, which always comes last: "Polished feature-film 3D animation, soft rounded shapes, expressive faces, soft plush fur, soft global illumination, cinematic lighting, snappy cartoon timing with strong poses and holds."
  - Every soul's model sheet and video starter end with this wording word for word, Astoria's included. A soul changes a shared phrase only where it would work against that character; the change is listed in STYLE.md, and the soul's Prompt pack says why. STYLE.md sanctions three such variants:
    - **Saberi:** "extra paws, extra legs, a second mechanical arm" replaces "extra limbs" in the negative, so it doesn't fight her third arm. Whenever Saberi is in frame, every soul's negative uses this replacement (STYLE.md), dropping "a second mechanical arm" when Sanchez, Tillman or B-1000 is also in frame (saberi.md co-star note).
    - **B-1000:** in his model sheets and solo shots, "glossy painted armour" replaces "soft plush fur" in the model-sheet wording and the video suffix, because he has no fur. In any shot shared with a furred character or the Huggable, the standard strings stay and his solo-only negative line is dropped [BBG News invention].
    - **Object sheets** (a prop with no face or fur, such as graham.md's deployed Turret): "Fan-art prop model sheet (front, side, back and three-quarter views) of *description*; polished stylized feature-film 3D animation prop, soft rounded shapes, clean painted metal robot parts, bold readable silhouette. Neutral grey background, even studio lighting, no text." [BBG News invention].
  - Apart from those, a shot changes the shared strings only by STYLE.md's per-shot rules: a shot that prompts a faceted effect swaps "low-poly" in the negative for "low-poly character models"; a clearly marked 2D flashback drops "flat 2D" and uses the matching 2D suffix; a shot with co-stars drops every negative term that describes a co-star; an organic-interior or break-apart KO shot adds "organs, viscera, wet flesh". Astoria needs no variant: her description adds "clean painted metal buckles, clips and scope fittings", because her design shows no visible robot parts.
  - **No outlines:** characters and sets get no ink or toon outline, even when a reference frame has one; only a marked 2D flashback draws them (STYLE.md, The look; maps overview §5.3 rule 12).
  - **Frame:** shorts are 9:16 vertical, with faces, sprites and on-screen text kept inside the Reels safe zone; model sheets are 16:9 landscape (STYLE.md, Frame).
- **Era.** Pick one era per short and say which, in the script header and the post caption [BBG News invention]. Everything in the short follows that era, using each soul's variant for it: skins, weapon looks and effect colours (which drift between years, weapons overview §2.5 and §3.1) and the map. The exceptions below are the only standing mixes; any other era appears only in a clearly marked flashback or skin gag.
  - **Classic (the default):** each character's BBG 2013 default skin, the in-game 3D model. Caption Steam-trailer and Steam-screenshot material "classic 2013 look" (weapons overview §3.7).
  - **2026 look:** take it only from 3.0.7 frames, the CT5 banner or demo footage; level-select tile art and 2026 footage from before the Oct 15 lighting pass are not proof of it (maps overview §5.1 rule 3). Caption a frame "2026 playtest" only if it comes from the 3.0.x builds (weapons overview §3.7).
  - **The Steam trailer and screenshots:** the Steam trailer SkyVu put on the 2026 Steam page and all five Steam screenshots are 2013 footage SkyVu re-used [Inference, strong]: the trailer's class cards are pixel-identical to SkyVu's May 30, 2013 trailer, and its gameplay matches that trailer's 160×90 storyboard (45 of 55 frames, the Graham segment and the Space Oddity clip included) [Observed]. So use them as a 2013 look reference only: call them "the Steam trailer" or "Steam screenshot screen_0N", caption them "classic 2013 look" where the era matters, never "2026 gameplay", and never rest a 2026-build claim on them alone [Inference]. The Space Oddity clip (about 30.0–32.8 s; Steam screen_01 is a frame of it) is no exception: the same moment, bloom included, is in the 2013 storyboard [Observed], so it is 2013 footage too [Inference, strong]; only why its pillar top blooms to near-white, which 2013–2021 fan captures lack, is [Unverified]. Nor is the Graham segment (about 7.25–10.5 s): it is 2013 footage too [Inference, strong], and the "2018 or later" reading of its toon outlines is withdrawn, because some 2013 fan captures already have them [Observed]; only why it is outlined is [Unverified].
  - **Exceptions** are explained in each file: Saberi (she debuted in BBG 2.4, Oct 2013 [Canon, BBG 2.4 notes], so she is dressed from her 2014 official art [Observed]) and Riggs (his 2013 outfit carries the 2026-banner Beebeegun model [BBG News invention]). Wil and Graham wear their in-game 3D defaults [Observed]; Graham's card in SkyVu's 2013 trailer is the Instagraham skin [Observed], and his card look is kept for card-era shorts, posters and flashbacks.
  - **Other eras** appear only in clearly marked flashbacks or skin gags: BB-1, BB Zombies and BLAST, which may use their own 2D looks (STYLE.md, 2D flashbacks); card-era looks, BB Zero and 2024 BB Heroes looks, in the house 3D style; and the franchise story locations (the Ursa Major, the Pink Planet, the H.I.P. complex), in labelled flashbacks only (maps overview §4). Mark every flashback in the edit, never in the prompt: an edit-added transition in and out and an original-art era tag such as "BB-1, 2010" (STYLE.md). BB Heroes looks are also for a short labelled as BB Heroes from its first frame. BB Heroes kit (Explosive Retreat, Sarcastic Air Strike, Doom Star and the rest of weapons overview §3.1's list) appears only in such a BBH-labelled short, never in a BBG-era short.
- **Settings.** Each short names one map or a plain set and follows STYLE.md's Sets and light: the map's documented time of day, its own practical light as the key, one landmark per shot, blank signs, and scenery team colour only as accents. From maps overview §5: tier every map element by its label before it goes in a script or prompt (§5.1 rule 1); never invent a hazard and present it as real (rule 2); never render Haunted Castle's gravestone names (§5.2 rule 6); keep official emblems abstract (rule 7); spell map names in captions as §5.4 does; keep the game's "SUICIDE" wording off screen (§5.5 rule 16).
- **Team colour:** red team by default; opponents default to the blue team, and in Free-For-All every opponent shows as Blue [Fan-wiki; Observed 2026] (maps overview §3; STYLE.md, Teams in frame). BBG 3D gear is team-coloured, so on the blue team the same skin's team-coloured parts turn blue [Fan-wiki; Observed]. Team colour shows on accents (for example the Soldier's headband, bands and ammo straps; the Huggable's flag; Tillman's armour; Astoria's pack, belt and gloves; Riggs's gear; Wil's helmet and print, per weapons overview §2.7; riggs.md and wil.md, after their dossiers, label the team link for Riggs's gear and for Wil's helmet, print and pad lights [Inference]), on the HUD and kill feed, and on Plant the Bomb gear [Observed; Fan-wiki]; Graham's backpack and gloves turn teal-blue [Observed; team link Inference] (graham.md). Every Prompt pack needs a blue-team line, not for pasting, naming the exact words that change (oliver.md's is the pattern); where the research is silent the point stays [Open] and the soul makes one labelled [BBG News invention] pick. A blue-team character gets its own sheet and Element. Among effects, only the Energy Barrier glow (v2.3+) is team-coloured in later BBG; the cloak aura (BBR v1.4.2 only) and the Peek A Boo neon lines (v1.4.2–v2.6) were removed [Fan-wiki]. Weapon projectiles keep their own colours [Inference]. Some Huggables in the Steam trailer and screenshots (2013 footage [Inference, strong]) carry a white rainbow-dot flag, not a team flag [Observed]; what it marks (perhaps a skin flag) is [Open].
- **Scale chart** (overall height, Oliver = 1.0× ears to feet; Botch measured while hovering; Graham measured to the top of his head under the hard hat, Wil to the top of his helmet and Sanchez to the top of his helmet dome, so Graham's hat (about 0.1×), Wil's ears and Sanchez's ear bumps rise above those values (graham.md, wil.md, sanchez.md); the Huggable's banner and Saberi's third arm not counted) [BBG News invention]: B-1000 ~1.5×, the biggest · Riggs ~1.2×, broad and heavy, second only to B-1000 · Oliver, Astoria (slimmer), Graham (stooped, reads shorter), Saberi (third arm reaches ~1.4×), Sanchez (lean; right arm ~1.5× the left) and Botch (hovering, slighter body) 1.0× · Wil ~0.9×, pear-shaped · Tillman ~0.9×, as wide as Riggs · Huggable ~0.65×, the shortest, a head below Wil. In prompts, give relative heights in words (STYLE.md, Co-stars in frame).
- **Shots.** Build every shot by STYLE.md's shot formula: attach the Element of every character in frame, then paste the acting character's line from its soul's video starter, one action (a weapon snippet replaces the starter's action, never adds to it), the scene line, "Vertical 9:16 framing." and the video suffix, last. Keep at most two characters with Elements on screen; several copies of one generic target count as one (STYLE.md habit 4). Describe every other character in frame in its own soul's words and back it with its Element; a generic opponent is the Huggable with its blue-team Element or, in a solo shot, a plain grey padded training dummy; in a Tutorial short, the Tutorial's orange lattice dummies (STYLE.md, Everyone in frame). Never leave a target or extra as an unnamed bear ("the target", "a rival"), which invites an off-model lookalike. In a shared shot the negative is the shared list once, plus each soul's own terms that survive every co-star's drop list; "solo shots only" lines stay out.
- **Reference images:** build Elements and start frames only from BBG News model sheets. Official art and fan frames are look references for the eye; if one must be attached, first crop it to the character and clean off the HUD, kill feed, reticles, timers, build stamps, chat, channel logos, watermarks, lettering and card backgrounds (STYLE.md habit 8; maps overview §5.2 rule 9).
- **Pronouns:** B-1000 is "he", the Huggable is "it", ABBi is "she".
- **Tone:** slapstick and deadpan. Make 15–45 second single-gag shorts that end on a hard cut, like the BB-1 cutscenes' "Hugged to DEATH!" endings [Canon, channel unconfirmed]. Arena matches and training bouts contradict nothing official [Inference]. The joke is the character's contradiction, never an accent or a real-world group.
- **Teen rating (13+):** cartoon violence only. No blood, gore or organs. A KO is a floppy, intact pratfall or, after some kills (a Phat Man blast, an irradiated target, one B-1000 close-range attack, B-1000's Last Resort, and kills from Bouncing Betty, Blast-O-Mole, Hand Cannon, Doom Cloud and Gravity Well), a pop into a few clean toy pieces [Observed; per-weapon attribution often Inference]; what decides which is unknown. Bears throw sparks and robots shed bolts and plates [BBG News invention; B-1000 really breaks into head, plates, claws and gun, Observed]. Melee contact pops a cluster of yellow five-point cartoon stars [Observed: 2013 and 2021 footage, and SkyVu's 2013 launch-trailer footage re-used on Steam in 2026]; beam hits throw pink four-point star sparks, bullet and explosive-round hits throw white or cream spiky starbursts, and a hit target flashes flat bright for about one frame [Observed]. The Sci-Fi rifles glow and hit in magenta [Observed]. Blue lightning-bolt tokens can drop where a bear dies [Observed]; that they are the wiki's three Joule pickups is [Fan-wiki; identification Inference], and their use as a kill marker in shorts is [Inference], but not in shorts set at the May–July 2013 launch, before v2.1 added them [Fan-wiki; leaving them out is Inference]. Huggables break into plush pieces with gold sparkles [Observed] or show white stuffing and a vertical rainbow column, as on SkyVu's 2023 merch art, not gameplay [Canon, merch art]; either may appear in a short, but never caption the merch look as the in-game look. Rainbow confetti is [BBG News invention], so never present it as the in-game look. Swearing is bleeped, cut off or swapped for a minced oath, after SkyVu's "WARNING! FCC Censorship!" gag. No slurs, sexual content or innuendo, crude taunts (Tea-Bagging is out), tobacco, alcohol or drugs.
- **Rights and content flags** (weapons overview §3.4–3.5; maps overview §5.2): no licensed music or lyrics. No mushroom-cloud or real-bomb framing for the Phat Man. Keep gore-flavoured source material off screen: the "Skinless" Oliver skin, the name "Blood Spurt", and the wiki's Tillman "pink and red flesh" and Seesaw blood trivia; draw the Field Medic's "amputated limbs" and the Zombee Gun's "bones" as olive plush chunks and toy parts. Keep these item-text lines off screen [Game text via wiki]: the alcohol jokes (Phat Man, Sake Bomb), "melt a face" (Steamshot), "stalking children" (the Not-So-Slenderman skin) and "ritalin" (Gummable). No recognisable third-party characters, costumes, songs, lyrics, choreography or signature gags: keep generic or off screen the Hulk (The Incredible Riggs), Mario (the Old School Graham skin), the Bullet Bill look of the Big Shot round, "Thriller" (the Kelowna kill and Thriller-style taunts) and the song the Greased Lightning text quotes, Space Oddity's "Death Star" hologram, Toxic Terror's Ninja-Turtle weapon rack, the Tutorial's Matrix-like code rain and any Halo- or Aliens-style look for the Pelican't. Riggs's "part Captain America, part Picard" is personality only, never costume.
- **Voices:** cast original performers only. Never clone or imitate a real person's voice; credited actors are history, not targets. Fan audio rips are for checking wording only. Whether a voice the video tool generates counts as an "original performer" is [Open], and the call is Bryce's (STYLE.md, Sound).
- **Sound:** music is original only, with no licensed music or lyrics, and pop-culture barks are spoken, never sung (oliver.md). Mouths follow each soul's face rules: the Huggable never lip-syncs, and Botch's flat mouth barely moves. The few documented game sounds keep their labels; every other effect is [BBG News invention] (weapons overview §3.6; STYLE.md, Sound). STYLE.md's Sound section has the rest.
- **On-screen text and narrator:** "post caption" means the text posted with the short; "on-screen text" means supers, era tags, narrator cards and status sprites, added in the edit only, in original art with no game UI fonts or logos, inside the Reels safe zone (STYLE.md, Frame and Status sprites) [BBG News invention]. A short may use an on-screen or voice-over narrator in SkyVu's mock-epic, self-aware register [Canon: the register, in SkyVu's video descriptions and map blurbs]; its lines are [BBG News invention].
- **Shared negative prompt:** add this to every file's own list: photorealistic fur, realistic anatomy, blood, gore, sexual content, real-person likeness, official logos, text, watermarks, morphing, extra limbs, low-poly, flat 2D. STYLE.md's sanctioned variants and its per-shot rules (see Rendering) are the only changes to it; where a tool has no negative field, follow STYLE.md's Negative lists and tools rule instead of pasting the list.
- **End card,** on every short, word for word:

  > Unofficial fan film, not affiliated with SkyVu; characters © SkyVu.

  Add it in the edit and hold it about 2 s inside the safe area (STYLE.md habit 6). No SkyVu or Battle Bears logos, wordmarks or app icons on the end card or the thumbnail (shared negative "official logos"; maps overview §5.2 rule 7). Whether the card should also say "AI" is [Open], and the call is Bryce's.

- **Post caption,** on every post: label the short an unofficial AI fan film (STYLE.md habit 7), for example "Unofficial AI fan film. Not affiliated with SkyVu.", name its era (see Era), and switch on the platform's AI-content label where it has one [BBG News invention]. The end card above stays word for word.

## Research and weapons

The research behind the souls lives in the Thallo site repo, not in this one: the weapons overview, `research_notes/BBG weapons (verified)/00_OVERVIEW.md`, with its dossiers; the maps overview, `research_notes/BBG maps (verified)/00_OVERVIEW.md`, with its per-map and topic dossiers (map and environment facts); and the lore report, `reports/Battle Bears character lore.md`, with its notes in `research_notes/Battle Bears character lore/`. The two overviews number their sections differently, so always name which one ("weapons overview §3.2", "maps overview §5.1").

Each soul's **Weapons** section, under Look, summarises the verified weapons research for that class: the default loadout and how it is carried, the kit, and each weapon's look, firing and impact, with notes on showing it in shorts and what is still unknown. The full dossiers, with every source, frame and sampled hex, live in the weapons folder; start with its overview. Labels are carried over from the dossiers and never upgraded. `[Unverified]` and the two fan-only tags, `[Fan video titles]` (tillman.md) and `[fan claim, InstableGR]` (astoria.md, a fan video description), are in the legend above; some souls write them as `[Open]`, which means the same. Several dossiers also tag hex values sampled from BBG game images `[Observed, sampled]`, while the legend above files sampled hexes under `[Inference]` and weapons overview §3.2 calls them estimates `[Inference]`. Some souls keep the dossier tag with a label note and some write `[Inference]`. Within one file a sampled value keeps one tag, and either way it is an estimate, never an official code.

## Rule: fan material stays fan material

Anything labeled `[Fan-wiki]`, `[Fan-wiki, Unverified]`, `[Inference]` or `[BBG News invention]` is fan material. In shorts, captions, descriptions and posts, present it as fan material and never as SkyVu canon: no "officially", no "in the lore", nothing that implies SkyVu confirmed it. When a short's premise rests on fan material about lore, a relationship or a backstory (Oliver's one-sided crush on Astoria, Sanchez's unfinished rescue, a "what if" where Saberi upgrades Sanchez's existing arm, though she is never named as his rebuilder), its description says it is a fan take. Quote `[Game text via wiki]` as "the in-game text, as the wiki quotes it", except the lines the Rights and content flags keep off screen.

Continuity: a dynamic between two characters appears in both files with the same wording and label, so change both or neither. Standing decisions: the Oliver–Astoria romance is not canon; no one is named as Sanchez's rebuilder; Riggs is not assumed to be the "Captain" Tillman begs to charge.
