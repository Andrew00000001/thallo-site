# Character reference sheets (house style)

These are the Element sheets: one 4K model sheet per character, in the feature-film 3D house style. Each sheet is attached as the character's reference in every image and video, to keep the look on-model.

- **Model:** Higgsfield Nano Banana Pro, 16:9, 4K (5504×3072), 4 credits a sheet.
- **Prompts:** taken word for word from each soul's Prompt pack. Full-resolution files stay in Higgsfield under the job IDs below. The JPGs here are 1600 px previews.
- **QA:** each sheet is checked against its soul's Look section before it becomes the Element.
  - **Pass:** ready to use.
  - **Minor:** a small detail is missing; usable.
  - **Fix:** needs a targeted edit pass first. The edit uses the sheet itself as the reference, so everything that is right stays.
- **Mirrored:** the model put every left/right detail on the wrong side, so the whole sheet was flipped horizontally (no credits). Upload the mirrored file as the Element; do not use the raw job output.
