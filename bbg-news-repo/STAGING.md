# Staging copy of Andrew00000001/bbg-news

This folder holds the full contents of the standalone BBG News bot repo (Instagram auto-poster, Discord "Send to BBG News" relay, and the 11 character souls), kept on this branch until the `bbg-news` repo exists on GitHub. Its workflows live in `bbg-news-repo/.github/`, where GitHub doesn't run them, so nothing here runs in the Thallo site repo.

To publish: copy everything in this folder (including `.github/`) to the root of the new `bbg-news` repo.
