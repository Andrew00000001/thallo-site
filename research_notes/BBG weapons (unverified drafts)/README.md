# Unverified drafts

These files are intermediate output from the BBG News research workflows, saved so finished work survives container restarts.
They have NOT been through the source/label and image verification passes yet. Do not use them for content until the verified dossiers replace them.

- `arsenal_*.json`: complete weapon inventories per class (names, slots, official text, mechanics, sources).
- `visuals_*.md` / `research_*.md`: first-draft dossiers (look, firing, projectile, impact; or map layout and look).
- `*.meta.json`: quick-reference rows, proposed corrections and open questions for the matching draft.
